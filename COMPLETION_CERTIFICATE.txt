SYSTEM ARCHITECTURE
═══════════════════════════════════════════════════════════════════════════

IP Blocking Prevention:
  1. Proxifly (GitHub CDN) → Fetch free proxies
  2. ProxyScrape API     → Additional proxy sources
  3. Validation         → Test each proxy against ThomasNet
  4. Pool Management    → Maintain 10+ working proxies
  5. Per-Vendor Rotation → New IP for each submission
  6. Failure Tracking   → 10-minute cooldown on failures
  7. Auto-Refill        → Replenish pool when below threshold

DataDome Bypass:
  1. Detection      → Iframe + content-based detection
  2. Solve          → CapSolver (primary) or 2Captcha (fallback)
  3. Retry 1-3      → Get new proxy + retry immediately
  4. Retry 4+       → Pause 5 seconds + retry
  5. Max Retries    → Skip vendor, return in 30 minutes
  6. Cookie Inject  → Apply solution to browser session

Rate Limiting:
  • 3-5 second random delay between vendors
  • ±1 second jitter to avoid pattern detection
  • 2 second delay between RFQs
  • Configurable thresholds via .env.dashboard
